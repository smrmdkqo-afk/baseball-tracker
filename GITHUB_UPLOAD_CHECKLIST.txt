Baseball Tracker Pro V5.2 GitHub 업데이트 체크리스트

1. 기존 Supabase가 V5 스키마라면 SQL 실행 불필요
2. supabase-config.js의 Project URL 확인
3. V5.2 폴더 안 파일 전체를 GitHub repository 최상위에 업로드/교체
4. index.html / app.js / styles.css / sw.js / manifest.webmanifest 교체 확인
5. Commit changes
6. GitHub Pages 주소 새로고침
7. 입력 탭에서 과거 날짜 선택 → 경기 투구 1개 입력 테스트
8. 홈으로 이동 → 오늘 수치가 변하지 않는지 확인
9. 기록 탭 → 과거 날짜에 이벤트가 나타나는지 확인
10. 분석 탭 → 해당 날짜가 포함된 기간 통계가 증가하는지 확인
11. 휴대폰/태블릿에서 동일 계정 동기화 확인
