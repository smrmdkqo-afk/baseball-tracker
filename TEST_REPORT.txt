Notes
-----
The reported 'static home screen / every click dead / no sync' condition is consistent
with the application module not reaching initialization. V6.2 used stable asset URLs,
which allowed a stale controlling service worker/browser cache to potentially mix
release assets during deployment. V6.2.1 prevents that class of update failure and
adds visible recovery if initialization is delayed or fails.
